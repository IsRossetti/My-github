# Git & GitHub - Guia Completo

![Git](https://img.shields.io/badge/git-%23F05033.svg?style=flat&logo=git&logoColor=white)
![GitHub](https://img.shields.io/badge/github-%23121011.svg?style=flat&logo=github&logoColor=white)

Página web interativa com guia prático para aprendizado de Git, GitHub e resolução de conflitos.

## Arquivos

- `index.html` - Página principal com todo o conteúdo
- `style.css` - Estilos e layout responsivo
- `README.md` - Documentação

## Conteúdo Abordado

- **Fundamentos**: Git, GitHub e configuração inicial
- **Comandos Essenciais**: init, clone, add, commit, push, pull
- **Branches**: Criação, merge, rebase e convenções de nomenclatura
- **Resolução de Conflitos**: Identificação e resolução passo a passo
- **Commits Semânticos**: Padronização de mensagens
- **Pull Requests**: Fluxo completo e templates
- **Comandos Avançados**: revert, reset, stash e emergências

## Deploy

**GitHub Pages:**
1. Settings > Pages
2. Source: branch `main`
3. Acesse: `https://isrossetti.github.io/My-github`

---

> **Nota**: Certifique-se que os arquivos estão salvos em UTF-8 para evitar problemas com acentos.
